# Diwali — Let there be light

A responsive, front-end-only Diwali celebration built with HTML, CSS, and JavaScript. Includes illustrated diyas, fireworks, optional synthesized ambient sound, and personalized greetings you can copy.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/ if it is not already installed.
2. Open PowerShell or Command Prompt in this folder.
3. Run `node server.js`.
4. Open the link printed in the terminal: http://localhost:3001.
5. Stop the server with `Ctrl+C`.

No npm install or build step is required. Google Fonts are optional; the page uses system fallbacks when offline.
